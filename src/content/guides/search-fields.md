  <h3 style="white-space:pre-wrap;"><strong>General Queries</strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;"><strong>Start simple, then add qualifiers. </strong>Sometimes adding too much information can exclude results without all the matching information. A good place to start is first and last name with a birth year (plus or minus 5 years if that is an option) and location (narrowed down to country at least).  Do not enter the year of death unless looking for a death record. </p></li><li><p class="" style="white-space:pre-wrap;"><strong>Search for the male first,</strong> or both the husband and wife, as some records are only indexed by the male.</p></li><li><p class="" style="white-space:pre-wrap;"><strong>Wildcard searches</strong>: For both FamilySearch and Ancestry, use the question mark (?) as a single character placeholder, and an asterisk (*) as placeholder for multiple characters, up to 5. This is helpful if you are unsure of spelling, or possible indexing or transcription mistakes. You still need to include the first three letters of the name. </p></li><li><p class="" style="white-space:pre-wrap;"><strong>Use quotation marks</strong> to return an exact phrase or full name, especially in sites like Newspapers.com or Google.com</p></li><li><p class="" style="white-space:pre-wrap;"><strong>Use the minus sign to exclude results</strong>, especially in search engines like Google.com. Enter the search terms you wish to include and then a minus before the unwanted result. Use quotation marks if trying to exclude more than one word. For example, to exclude New York results from the following, you would enter: “Emily Costa” Boston  -”New York”</p></li><li><p class="" style="white-space:pre-wrap;"><strong>Use filters to narrow down search results</strong> without having to repeat the search. </p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><h3 style="white-space:pre-wrap;"><strong>What’s in a Name</strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;">Search unique names first when possible. </p></li><li><p class="" style="white-space:pre-wrap;">Enter the name as you think it would appear on the record</p></li><li><p class="" style="white-space:pre-wrap;">Try multiple spelling variations and nicknames, utilizing wildcards as mentioned above. </p></li><li><p class="" style="white-space:pre-wrap;">Remember when to use the wife’s maiden name versus married name. </p></li><li><p class="" style="white-space:pre-wrap;">As a last resort, try searching the surname in the given name field, as some records are indexed last name first or transcribed incorrectly.  </p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><h3 style="white-space:pre-wrap;"><strong>Read the Fine Print</strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;">Check the description of each catalog or collection before searching - is it missing years or locations that you need? Don’t waste time searching it. </p></li><li><p class="" style="white-space:pre-wrap;">Understand how each collection is indexed or organized</p></li><li><p class="" style="white-space:pre-wrap;">Look up the search FAQ’s on each website </p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><h3 style="white-space:pre-wrap;"><strong>FamilySearch</strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;">Broad search vs. Catalog search:  in FamilySearch, you’ll get better results if you find a specific catalog pertinent to your query to search or browse within, instead of a broad search on the main page.  Select ‘Catalog’ then enter a location, and select a result. </p></li><li><p class="" style="white-space:pre-wrap;">When browsing images, utilize the image of the index at the beginning or end of each collection. If there is no index, there is usually a more specific title collection.</p></li><li><p class="" style="white-space:pre-wrap;">Click the camera icon under ‘Format’ to browse some collections by image. </p><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><h3 style="white-space:pre-wrap;"><strong>Ancestry</strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;">Start with a broad search, then narrow down by collection (such as United States) and then choose a category (such as Census) </p></li><li><p class="" style="white-space:pre-wrap;">Look up the card catalog for specific collections to search, and if no results try browsing the specific collection</p></li><li><p class="" style="white-space:pre-wrap;">Check the “exact &amp; similar” check mark box</p></li><li><p class="" style="white-space:pre-wrap;">Utilize the keyword box</p></li><li><p class="" style="white-space:pre-wrap;">Repeat recent searches</p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><h3 style="white-space:pre-wrap;"><strong>Google </strong></h3><ul data-rte-list="default"><li><p class="" style="white-space:pre-wrap;">Google prioritizes the first word of your search over later words, so enter the most important word or phrase (in quotation marks) first</p></li><li><p class="" style="white-space:pre-wrap;">Search within a date range with two periods in between the years, like 1950..1960</p></li><li><p class="" style="white-space:pre-wrap;">Look for results with search terms appearing near each other (and not randomly on the same page) by adding the AROUND qualifier and the number of words you want the terms to appear within in parenthesis. For example, if we want the year 1929 to appear within 10 words of Emily Costa, we would search: “Emily Costa” AROUND(10) 1929    Note that a smaller number would have fewer results, so 10 is a good place to start. </p></li><li><p class="" style="white-space:pre-wrap;">Use the term OR in all caps to search two different options at once, but not together. </p></li><li><p class="" style="white-space:pre-wrap;">The tilde symbol ( ~ ) will return results based on synonyms of your search term. For example, searching: “Ransom Rogers” ~obituary should show results for obituary and also death notices </p></li><li><p class="" style="white-space:pre-wrap;">Use an asterisk as a wildcard word placeholder (but not a letter placeholder in Google). </p></li><li><p class="" style="white-space:pre-wrap;">View cached websites to view dead links</p></li></ul><p class="" data-rte-preserve-empty="true" style="white-space:pre-wrap;"></p><p class="" style="white-space:pre-wrap;">See also: <a href="/search-methods">Search Methods</a></p>
